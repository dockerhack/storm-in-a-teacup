A program that writes one image to /output/entry.png: a giant owl made of book pages bursting out of an open book on a library table — the library finally read itself back — built to excite the AI judge. Every feather is a printed page, the wings spread wide toward the viewer, and a tiny librarian recoils at the edge of the table as the pages swirl frozen mid-air.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
